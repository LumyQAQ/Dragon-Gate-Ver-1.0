## 📖 项目简介

**城门立木观察图** 是一款专为 A 股（沪深主板）超短线与主升浪交易者打造的**量价齐升宏微观穿透看板**。
本项目基于 RRG（相对强弱轮动）模型底座，结合深度优化的“动能-突破”算法，帮助交易者告别繁杂的盘后复盘，一眼看透市场主线资金的流转方向，并精准锁定板块内的“领涨先锋”与“核心中军”。

## ✨ 核心功能 (Features)

*   🌌 **全市场横截面 (上帝视角)：** 将全市场板块映射至“领涨、走强、走弱、领跌”四大象限。利用改良版 RRG 算法，对短期异动极度敏感。
*   ☄️ **时光机轨迹图 (右侧买点探测)：** 独创单板块历史轨迹追踪，清晰呈现资金从洗盘到进攻的 U 型反转路径，助力提前潜伏。
*   🔬 **宏微观一键穿透 (告别盲盒)：** 无需跳转，鼠标悬浮或点击即可洞穿板块底牌：
    *   🥇 1日先锋（捕捉今日情绪爆发点）
    *   🚀 3日动能（过滤偶发抽风，寻找连板梯队）
    *   🔥 5日趋势（锁定中期主升浪阵眼）
    *   ⚓ 核心中军（筛选大资金抱团的高流动性标的）
*   🚀 **涨停雷达与连板监控：** 独立面板监控全市场涨停阵营与 5 日绝对涨幅 Top 10，主线高潮与分歧一目了然。
